# Changelog

Notable user-facing changes are recorded here. Versions follow Semantic Versioning where applicable.

## [0.1.0] - 2026-09-17

### Added

- First public Apple Silicon release of the Craft Bridge macOS menu bar app.
- Local Obsidian search index and stdio MCP tools.
- Obsidian desktop companion plugin for editor context and local link insertion.
- Preview-first cross-link changes with hash checks, local backups, read-back verification, and rollback support.
- First-run Vault selection, Keychain-backed Craft API Connection setup, plugin installation, and local diagnostics.
